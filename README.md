# Piano Trainer
A simple Java command-line flashcard tool designed to help beginners practice reading piano sheet music, test note recognition, and track scores.
## Project Goal
To provide an application that helps people improve their sight-reading speed and accuracy for standard piano notes.
## Tech Stack
Language: Java
Libraries/Tools: Standard Java libraries
Data Storage: A simple plain text file (scores.txt) to save high scores or practice progress
Data Sources: None (or maybe some sheet music on Musescore)
